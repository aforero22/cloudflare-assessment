## Can the order be changed? No.
- Cloudflare renders the login page with a fixed layout: IdP buttons ("Sign in with:") come first, then "or", then
  the e-mail (One-time PIN) form. Changing allowed_idps had no effect on the layout (same order before and after).
- allowed_idps is a set in the Terraform provider (no order), and the docs list only branding options for the
  login page (name, logo, header, footer, background colour), with no ordering control.
- What we can do: the e-mail form's "Send login code" is the page's primary (blue) button and the GitHub button is a
  neutral one. README and docs/ACCESS.md tell reviewers to use the e-mail form and treat GitHub as optional.

## What went wrong first (kept for honesty)
1. The GitHub OAuth app client ID was transcribed by hand into the dashboard with two look-alike characters
   ("0v23Ii..." instead of "Ov23li..."). The IdP saved without complaint; the dashboard "Test" opened a GitHub 404.
2. Finding the right value: GitHub's sign-in page names the OAuth app ("to continue to <app>") only for a valid
   client ID, which identified "Ov23liHGsF1STW7lSMa9" among the look-alike variants.
3. Fix: client ID corrected in the dashboard and, as a precaution, a new client secret generated on GitHub (old one
   deleted) and set in Zero Trust; dashboard "Test" then reported "Your connection works!".
Lesson: copy/paste OAuth client IDs (never retype them), and run the IdP "Test" immediately after saving.
